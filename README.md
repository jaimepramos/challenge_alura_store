# Projeto de Otimização de Portfólio: Caso de Estudo "Lojas de Varejo de João"

## Descrição do Projeto

Este projeto apresenta uma análise abrangente de desempenho das unidades de varejo na rede de lojas de João. O objetivo principal foi consolidar dados de vendas de quatro lojas distintas, identificar padrões de consumo, custos logísticos e métricas de satisfação do cliente para apoiar uma decisão estratégica: qual unidade deveria ser desinvestida para garantir a saúde financeira da rede?

A análise abrange receita bruta através da distribuição geográfica de vendas, utilizando técnicas de limpeza, transformação e visualização de dados.

## Tecnologias e Bibliotecas

- **Python 3.x**
- **Pandas**: Processamento e manipulação de DataFrames
- **NumPy**: Operações matemáticas e vetorização
- **Matplotlib**: Geração de gráficos estatísticos
- **Folium**: Mapeamento interativo e análise geoespacial
- **Google Colab**: Ambiente de desenvolvimento em nuvem

## Funcionalidades Principais

- **Consolidação de Dados**: Importação automatizada de múltiplos arquivos CSV via URL
- **Análise de Receita**: Cálculo de receita total por unidade para identificar líderes de mercado
- **Avaliação de Satisfação**: Mapeamento de classificações de clientes para medir NPS simplificado (Net Promoter Score)
- **Estudo de Popularidade**: Identificação de produtos e categorias mais e menos vendidos por região
- **Análise Logística**: Cálculo de custo médio de frete correlacionado com métricas de satisfação
- **Inteligência Geográfica**: Mapeamento de latitude e longitude para visualizar concentração de vendas

## Principais Insights

- **Unidade Crítica**: A Loja 4 apresenta o cenário mais crítico com baixa receita e custos de frete elevados
- **Correlação Logística**: Correlação direta observada entre altos custos de frete e diminuição dos índices de satisfação do cliente
- **Dominância de Categorias**: Eletrônicos e Móveis impulsionam a receita primária, mas são mais sensíveis a variações de frete baseadas em localização

## Instruções de Execução

1. Acesse o projeto via Google Colab
2. Verifique se as dependências (pandas, matplotlib, folium) estão instaladas (padrão no Colab)
3. Execute as células sequencialmente
4. Visualizações (gráficos e mapas) serão geradas automaticamente em cada etapa da análise

## Recomendação do Consultor

A análise técnica recomenda o desinvestimento da Loja 4, baseado na ineficiência operacional demonstrada onde os custos logísticos comprometem a viabilidade competitiva em relação às outras unidades da rede.
